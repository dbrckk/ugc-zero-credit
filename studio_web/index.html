4. Voix IA locale · Français / English

Installer un modèle Piper pour chaque langue sur le serveur. Aucun appel API et aucun lip-sync automatique.

Après génération, écouter le WAV dans la bibliothèque de médias. Il ne peut pas être utilisé comme clip parlant sans vidéo synchronisée.

5. Short narré — photos + voix FR / EN

Produit une vraie vidéo verticale avec tes photos et un WAV Piper du projet. Les photos restent visibles sans visage fictif ni fausse synchronisation labiale.

Mention affichée dans la vidéo : PUBLICITÉ · CONTENU GÉNÉRÉ AVEC IA. Aucun sous-titre mot à mot inventé.

6. Portrait parlant — MuseTalk local (GPU)

Cette option nécessite un GPU NVIDIA CUDA et MuseTalk 1.5 déjà installés sur le serveur. Elle réutilise le WAV Piper sans régénérer la voix. Aucun crédit d'API.

La vidéo obtenue reste à vérifier avant publication : mouvements des lèvres, voix, expression, fidélité du produit et droits commerciaux. Le GPU peut être indisponible même si MuseTalk est configuré.
